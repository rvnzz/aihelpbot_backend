# Архитектура AIHelpBot Backend

## 🏗 Структура приложения

### API Endpoints (`src/app/api/v1/endpoints/`)
- `auth.py` - Эндпоинты аутентификации
  - Регистрация пользователей
  - Аутентификация
  - Управление токенами
- `users.py` - Эндпоинты пользователей
  - Управление пользователями
  - Профили пользователей
- `chat.py` - Эндпоинты чата
  - Обработка сообщений
  - Управление диалогами
- `documents.py` - Эндпоинты документов
  - Управление документами
  - Обработка файлов

### CRUD операции (`src/app/crud/`)
- Операции с базой данных
- Бизнес-логика приложения
- Взаимодействие с моделями

### Модели (`src/app/models/`)
- SQLAlchemy модели
- Определение структуры данных
- Связи между моделями

### Схемы (`src/app/schemas/`)
- Pydantic модели
- Валидация данных
- Сериализация/десериализация

### Основные компоненты (`src/app/core/`)
- Конфигурация приложения
- Безопасность
- Общие утилиты

## 🔄 Взаимодействие компонентов

1. **API Endpoints**
   - Принимают HTTP запросы
   - Валидируют входные данные через схемы
   - Вызывают CRUD операции

2. **CRUD операции**
   - Реализуют бизнес-логику
   - Взаимодействуют с моделями
   - Обрабатывают данные

3. **Модели**
   - Определяют структуру данных
   - Управляют связями между данными
   - Обеспечивают целостность данных

4. **Схемы**
   - Валидируют данные
   - Преобразуют данные между форматами
   - Обеспечивают безопасность типов

## 🛡 Безопасность

- JWT аутентификация
- Валидация данных
- Защита от SQL-инъекций
- Управление сессиями

## 📝 Примечания

- Проект построен на FastAPI
- Использует SQLAlchemy для работы с БД
- Pydantic для валидации данных
- Асинхронная обработка запросов
- RESTful API архитектура
