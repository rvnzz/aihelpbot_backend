# Модели данных AIHelpBot Backend

## 👤 Модель User

### Описание
Модель пользователя системы с различными ролями и связями с другими сущностями.

### Поля
- `id` (Integer) - Уникальный идентификатор пользователя
- `email` (String) - Email пользователя (уникальный)
- `hashed_password` (String) - Хешированный пароль
- `role` (Enum) - Роль пользователя (ADMIN, MANAGER, USER)

### Связи
- `documents` - Связь с документами (один-ко-многим)
- `chats` - Связь с чатами (один-ко-многим)

## 💬 Модель Chat

### Описание
Модель чата, представляющая диалог между пользователем и системой.

### Поля
- `id` (Integer) - Уникальный идентификатор чата
- `title` (String) - Заголовок чата
- `created_at` (DateTime) - Дата и время создания
- `user_id` (Integer) - ID пользователя-владельца

### Связи
- `user` - Связь с пользователем (многие-к-одному)
- `messages` - Связь с сообщениями (один-ко-многим)

## 📝 Модель ChatMessage

### Описание
Модель сообщения в чате, различающая сообщения пользователя и системы.

### Поля
- `id` (Integer) - Уникальный идентификатор сообщения
- `content` (Text) - Текст сообщения
- `is_user` (Boolean) - Флаг принадлежности сообщения пользователю
- `created_at` (DateTime) - Дата и время создания
- `chat_id` (Integer) - ID чата

### Связи
- `chat` - Связь с чатом (многие-к-одному)

## 📄 Модель Document

### Описание
Модель документа, загруженного пользователем в систему.

### Поля
- `id` (Integer) - Уникальный идентификатор документа
- `title` (String) - Название документа
- `file_path` (String) - Путь к файлу
- `file_type` (String) - Тип файла
- `uploaded_at` (DateTime) - Дата и время загрузки
- `uploaded_by` (Integer) - ID пользователя, загрузившего документ

### Связи
- `uploader` - Связь с пользователем (многие-к-одному)

## 🔄 Связи между моделями

1. **User ↔ Document**
   - Один пользователь может загрузить множество документов
   - Каждый документ принадлежит одному пользователю

2. **User ↔ Chat**
   - Один пользователь может иметь множество чатов
   - Каждый чат принадлежит одному пользователю

3. **Chat ↔ ChatMessage**
   - Один чат содержит множество сообщений
   - Каждое сообщение принадлежит одному чату

## 📝 Особенности реализации

- Используется SQLAlchemy ORM
- Все модели наследуются от `Base`
- Реализованы каскадные удаления для связанных сущностей
- Используются индексы для оптимизации запросов
- Временные метки автоматически устанавливаются при создании
