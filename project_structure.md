# Структура проекта AIHelpBot Backend

## 📁 Основные директории

```
.
├── src/                    # Исходный код приложения
├── tests/                  # Тесты
├── models/                 # Модели данных
├── .vscode/               # Настройки VS Code
└── .venv/                 # Виртуальное окружение Python
```

## 📄 Конфигурационные файлы

- `pyproject.toml` - Конфигурация проекта Python
- `requirements.txt` - Зависимости проекта
- `.env` - Конфигурация окружения
- `.env.example` - Пример конфигурации окружения
- `docker-compose.yml` - Конфигурация Docker Compose
- `Dockerfile` - Конфигурация Docker
- `uv.lock` - Файл блокировки зависимостей

## 📚 Документация

- `architecture.md` - Архитектура проекта
- `database_schema.md` - Схема базы данных
- `database_schema.puml` - UML диаграмма базы данных
- `technical_implementation.md` - Техническая реализация
- `rag_process.md` - Документация по RAG процессу

## 🏗 Структура приложения (`src/app/`)

```
src/app/
├── api/                   # API endpoints
├── core/                  # Основные компоненты
├── crud/                  # Операции с базой данных
├── models/               # Модели данных
├── schemas/              # Схемы данных
├── cli/                  # Командная строка
├── main.py              # Точка входа приложения
└── __init__.py
```

## 🛠 Скрипты управления

- `manage.sh` - Скрипт управления
- `run_tests.py` - Запуск тестов
- `aihelperbackend.py` - Основной скрипт

## 🛡 Технологии и практики

- **Docker** - Контейнеризация
- **Python Virtual Environment** - Изолированное окружение
- **UV** - Система управления зависимостями
- **Markdown** - Документация
- **RAG** - Retrieval-Augmented Generation
- **FastAPI** - Веб-фреймворк
- **Модульная архитектура** - Разделение на компоненты
- **Тестирование** - Автоматизированные тесты

## 📝 Особенности проекта

- Современная архитектура
- Четкое разделение ответственности
- Документированный код
- Поддержка Docker
- Система тестирования
- Использование RAG технологий
