# Контроллеры и представления AIHelpBot Backend

## 🎮 Контроллеры

### Класс `UserController`
- `auth_post` - Обработка POST-запроса для аутентификации пользователя
- `registr_post` - Обработка POST-запроса для регистрации нового пользователя
- `showForm` - Отображение формы для создания нового пользователя
- `delete_user` - Удаление пользователя
- `UserView` - Отображение списка всех пользователей
- `logout` - Выход пользователя из системы

### Класс `OrderController`
- `showStatus` - Отображение формы для создания нового заказа с возможными статусами
- `Create_order` - Обработка POST-запроса для создания нового заказа
- `OrderView` - Отображение всех заказов

### Класс `MeasurementController`
- `Create_measurement` - Обработка POST-запроса для создания новых замеров
- `MeasurementView` - Отображение замеров
- `removeFeedback` - Метод для удаления заявки обратной связи

### Класс `SpecificationController`
- `Create_specification` - Обработка POST-запроса для создания новой спецификации
- `SpecificationView` - Отображение всех спецификаций

## 📊 Модели

### `User`
- Модель пользователя
- Содержит информацию о пользователе системы

### `Order`
- Модель для заказов
- Хранит информацию о заказах пользователей

### `Measurement`
- Модель замеров
- Содержит данные о проведенных замерах

### `Specification`
- Модель спецификаций
- Хранит информацию о спецификациях

## 🎨 Представления

### Общие компоненты
- `header` - Компонент, используемый на всех страницах

### Пользователи
- `Create_user` - Представление для создания пользователей
- `List_user` - Представление для списка пользователей
- `auth` - Представление для страницы авторизации

### Заказы
- `create_order` - Представление для создания заказов
- `list_order` - Представление для списка заказов
- `list_order_full` - Представление для подробной информации о заказе

### Дополнительные представления
- `measurement` - Представление для страницы замеров
- `specification` - Представление для страницы спецификаций

## 📝 Примечания

- Все представления используют общий компонент `header`
- Контроллеры реализуют RESTful API endpoints
- Модели используют SQLAlchemy для работы с базой данных
- Представления используют FastAPI шаблонизатор
